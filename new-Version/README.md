# Thought of Journey

A responsive React + Vite web application for saving, searching and exploring thoughts and journey moments.

## Highlights

- Responsive mobile, tablet and desktop layout
- Reusable React component architecture
- Search and category filtering
- Add and delete personal thoughts
- LocalStorage persistence
- Loading and empty states
- Accessible controls and keyboard focus
- Reduced-motion support
- Lazy-loaded decorative images
- Production-ready Vite build

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- Lucide React icons

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## GitHub

Do not commit `node_modules`. The included `.gitignore` prevents it from being uploaded.

```bash
git add .
git commit -m "Improve architecture responsive design performance and documentation"
git push origin main
```
